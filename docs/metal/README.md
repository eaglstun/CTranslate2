# Metal backend documentation

The current Metal backend documentation stays at the repository root because it is the
main feature of this fork:

- [`METAL_BACKEND.md`](../../METAL_BACKEND.md) — architecture, supported operations,
  milestones, and contributor constraints.
- [`METAL_BENCHMARKS.md`](../../METAL_BENCHMARKS.md) — benchmark methodology, results,
  profiles, and rejected performance ideas.
- [`METAL_NEXT_STEPS.md`](../../METAL_NEXT_STEPS.md) — the single active engineering
  backlog.

Additional material:

- [Contribution options](contribution-options.md) — optional writeup and upstream-discussion
  follow-ups; not an engineering backlog.
- [Historical records](history/) — completed implementation plans, bring-up notes, and
  postmortems retained for design context.

When documents disagree, prefer the current backend document and active backlog over a
historical record.
