# apple-silicon skill

Metal / Apple Silicon GPU documentation reference for the CTranslate2 Metal backend.

Entry point is [SKILL.md](SKILL.md); the actual docs live in [references/](references/).
Each reference is condensed from Apple's developer documentation (source URL cited at
the top) and ends with a section tying the API to specific files in `src/metal/`.

`scripts/` is reserved for future helpers (e.g. a DocC-JSON fetcher); empty for now.
